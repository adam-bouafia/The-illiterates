# The Illiterates

My personal learning journal, no fluff, no slides-only sessions. I learn
by doing, and I write each session down in enough detail that I (or
anyone starting from zero) can follow it later without having to
remember what was in my head at the time.

## Or Run Locally

```bash
cd "The illiterates"
./serve.sh
# Opens at http://localhost:8000
```

Requires Python 3. The script creates a virtual environment and installs MkDocs automatically.

## Structure

Each session has its own folder under `docs/` with theory chapters and hands-on labs.

```
docs/
  01-kubernetes-basics-101/
    theory/    - Explanatory material
    labs/      - Step-by-step exercises (Fedora Linux)
    resources.md
```
