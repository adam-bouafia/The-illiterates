# The Illiterates

My personal learning journal, no fluff, no slides-only sessions. I learn
by doing, and I write each session down in enough detail that I (or
anyone starting from zero) can follow it later without having to
remember what was in my head at the time.

## How It Works

- My own sessions, on my own schedule
- Theory first, then hands-on labs against the real thing - a real cluster,
  a real cloud subscription, real commands and real output
- Everything runs on Fedora Linux
- Every session is written assuming zero prior knowledge of that topic,
  even where I already "know" it - writing it from scratch is how I find
  out what I actually understand versus what I've just memorized
